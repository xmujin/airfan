CPU风扇：
黑色（Ground，地线）：这是地线，用于电气回路的负极。

黄色（+12V 电源）：这是电源线，通常提供 12V 的电压给风扇。

绿色（Tachometer，转速信号）：这是转速信号线，风扇通过这根线向主板报告当前的转速。

蓝色（PWM，脉冲宽度调制）：这是 PWM 控制线，用于调节风扇的转速。主板通过调节这根线的信号频率来控制风扇的转速。
